# SHADOW 3D PROJECT v9

Versão refeita para deixar o conteúdo visual realmente evidente.

## Tem
- Hero com imagem + vídeo local em loop.
- Mural de fotos com 10 cards.
- 6 frames extraídos do `videoplayback.mp4`.
- 3 cenas adicionais.
- Lightbox para abrir as imagens grandes.
- 2 players de vídeo locais:
  - `videoplayback.mp4` (arquivo enviado)
  - `chaos-loop.mp4`
- História + timeline.
- Dossier de dados.
- Assinatura gigante `ZJuiceX` no final.
- Parallax e interface cinematográfica no modo Vite.
- `preview.html` que funciona diretamente sem npm.

## Rodar com Vite
```bash
npm install
npm run dev
```

## Abrir preview
Abra `preview.html` diretamente no navegador.

## Arquivos
O pacote contém os assets locais para não depender de caminhos externos.
